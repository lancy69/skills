# Raise Issue

Raise an issue to the repository chosen by user.
If user did not specify a repository, inferr it from current project's `git remote` outputs.

Before you create the issue, make sure to check for existing duplicate issues.
If one or more duplicate issues exist, do not create a new one.
Instead, report to user about these duplicates: show links and short descriptions for each.

Attach any artifacts provided by user if it helps better demonstrate the problem.
